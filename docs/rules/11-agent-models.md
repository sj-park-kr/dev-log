## 11. 작업별 모델
Claude와 Codex는 공통 작성 프롬프트와 검토 절차를 따른다. 서브에이전트를 띄울 때는 실행 중인 공급자에 맞춰 `model` 파라미터를 명시한다.

| 작업 | Claude `model` | Codex `model` | 비고 |
|---|---|---|---|
| 글 작성·수정 | `opus` | `gpt-6.2-astra` | 본문 구성, 비유, 슬라이드 문장, 검토 의견 반영 포함 |
| 자료 조사 | `sonnet` | `gpt-6.2-sol` | [사실 확인](07-fact-checking.md)에 따라 공식 출처와 함께 보고 |
| 양식 검토 | `sonnet` | `gpt-6.2-sol` | [양식 검토](08-review.md#8-0-양식-검토-초보자-검토-전) |
| 초보자 페르소나 검토 | `sonnet` | `gpt-6.2-sol` | [초보자 페르소나 검토](08-review.md#8-초보자-페르소나-검토) |

- 메인 세션이 표의 글 작성 모델이면 직접 써도 된다. 그 외에는 해당 모델의 서브에이전트에 글 작성을 맡긴다. 사용자가 서브에이전트를 요청하면 직접 작성할 수 있는 경우에도 위임한다.
- 오탈자나 한두 단어 수준의 수정은 메인이 직접 해도 된다.
- 글 작성 서브에이전트에게는 [AGENTS.md](../../AGENTS.md)의 글 작성 문서(블로그 정체성, 글 구성, 페이지 문장, SVG 규칙)와 기준 예시 `_posts/kafka/2026-11-15-why-kafka.md`를 먼저 읽게 한다.
- 양식 검토와 초보자 페르소나 검토는 글마다 각각 새 서브에이전트를 띄워 순서대로 진행한다. 실제로 다른 모델을 썼다면 모델과 이유를 완료 보고에 적는다.
- 영상 제작은 [영상 규칙](12-youtube-video.md#모델)에 따라 Opus로 진행한다. effort는 `xhigh`, 최소 `high`다.
