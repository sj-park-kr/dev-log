## 5. 그림 규칙 (인라인 SVG)

동화책의 주인공은 그림이다. 페이지마다 큰 그림 한 장이 그 페이지의 생각 하나를 혼자서 보여 줘야 한다. 기준 예시는 [Kafka 1편](../../_posts/kafka/2026-11-15-why-kafka.md)이다.

### 기본
- 이미지 파일 대신 본문에 `<svg class="dg" viewBox="0 0 400 H" role="img" aria-label="그림 내용을 문장으로">`를 넣는다. 가로는 400 기준으로 그리고 높이(H)는 내용에 맞춘다(보통 170~310). `storybook` 글에서는 CSS가 최대 560px까지 키워 보여 준다.
- `aria-label`에는 그림이 보여 주는 내용 전체를 문장으로 쓴다. 설명용 숫자면 "시간은 설명용 예시다"처럼 밝힌다.
- 텍스트 도식(ASCII)은 쓰지 않는다.

### 그림 하나 = 생각 하나
- 한 그림에는 그 페이지 제목이 말하는 것 하나만 그린다. 두 가지를 말하고 싶으면 페이지를 나눈다.
- **글자는 이름표만 쓴다.** 아이콘 아래 `big` 이름표(2~4글자)나 `chip` 라벨 한두 마디가 기본이다. 그림 안의 문장형 글자(`small`·`alert`)는 그림 하나에 1~2개까지만 둔다.
- 비유 이름이 먼저고 실제 용어는 그 아래 `small`로 작게 붙인다. 예: `big` "가게" + `small` "프로듀서".
- 사물은 글자 상자 대신 아이콘으로 그린다(아래 "아이콘으로 그리기"). 순서·번호처럼 아이콘이 없는 것만 상자(`rect`)와 숫자로 그린다.

### 나란히 비교 (전후·두 방식 비교)
- **비교할 두 가지는 반드시 한 그림 안에 나란히 그린다.** 페이지를 나눠 따로 그리거나 버튼으로 바꿔 보게 하지 않는다.
- 위아래 두 카드(시간 흐름 비교) 또는 좌우 두 카드(성질 비교)로 그린다. 카드는 `<rect class="line" rx="12"/>`, 카드 제목은 `class="label center"`로 카드 안 가운데에 둔다.
- 두 카드는 **같은 기준**으로 그린다. 시간 비교라면 같은 시간 축(같은 x 위치에서 시작), 성질 비교라면 같은 아이콘과 같은 개수로 그리고 다른 점만 색으로 드러낸다.
- 예: 1편의 `직접 부르면 느린 곳을 기다려요`(위아래 시간 막대), `메시지 큐는 지우고 카프카는 남겨요`(좌우 카드), `이럴 때 써요, 이럴 땐 안 써요`(좌우 목록 카드).

### 색 (클래스로만 지정)
| 클래스 | 용도 |
|---|---|
| `kafka` | 주인공·좋은 쪽(노란색) |
| `bad` | 문제가 생긴 곳·느린 곳(빨간색) |
| `box` | 중립 |
| `new` | 새로 생긴 것·보관한 것(초록 점선) |
| `line` / `line dash` | 연결선·카드 테두리 / 점선 |
| `mark` | 위치 표시 삼각형 |
| `big` | 아이콘 아래 이름표(17px 굵게) |
| `chip` | 작은 라벨 |
| `small` | 보조 글씨(회색) |
| `alert` | 빨간 보조 글씨 |
| `label` | 왼쪽 정렬 소제목, `class="label center"`면 가운데 |
| `ic` | 아이콘 선 스타일(`<use class="ic">`) |
| `mono` | 코드·주소 글씨 |

- 색을 직접 쓰지 않는다(다크 모드 때문). 한 글에서 같은 뜻에는 같은 색을 쓴다. 짝이 되는 둘은 같은 아이콘에 색만 다르게 한다.

### 아이콘으로 그리기
- **스프라이트**: 글 맨 위(`<div class="lesson …">` 바로 안)에 숨긴 `<svg width="0" height="0" style="position:absolute" aria-hidden="true" focusable="false"><defs>…</defs></svg>`를 두고 `<symbol id="i-이름" viewBox="0 0 24 24">`로 그 글에서 쓰는 아이콘만 정의한다. 빈 줄을 넣지 않는다. 첫 줄 주석에 원본 주소·버전·라이선스와 이름이 다른 아이콘의 대응(예: `i-check=circle-check`)을 적는다.
- **가져오기**: [Lucide](https://lucide.dev)(ISC)에서 `https://cdn.jsdelivr.net/npm/lucide-static@<버전>/icons/<이름>.svg`의 `<path>` 값을 옮긴다. 버전을 고정하고(현재 1.25.0) `latest`는 쓰지 않는다. 직접 그리지 않는다. 쓸 만한 아이콘이 없을 때만 24x24 칸에 같은 굵기로 그리고 주석에 직접 그렸다고 밝힌다.
- **사용**: 색 원 위에 얹는다. `<circle class="kafka" cx cy r/><use class="ic" href="#i-warehouse" x y width height/>`
- **크기**: 이 페이지의 주인공은 r 40~48에 아이콘 48~56, 보통은 r 24~32에 아이콘 32~44, 작은 표시는 r 14~20에 아이콘 18~26.
- 쓰는 `i-…`가 모두 스프라이트에 정의돼 있는지 확인한다.
- 라이선스 전문은 `assets/icons/LICENSE-lucide.txt`에 있다. 다른 아이콘 세트를 쓰면 그 라이선스도 같은 폴더에 넣는다.

### 화살표와 겹침
- `<marker>` id는 글 전체에서 겹치지 않게 짓는다(예: `sb1, sb2…`). marker의 `path`에는 fill을 직접 쓰지 않는다.
- 한글은 글자 폭이 넓다. 이름표 글자 수 × 약 17px(`big`) 또는 13px(`chip`·`small`)로 폭을 어림해 서로·아이콘·카드 테두리와 겹치지 않게 둔다. 오른쪽 끝(x 400)을 넘지 않는지 확인한다.
- 화면에서 글자 잘림과 겹침을 확인한다. 확인하지 못했으면 그렇다고 보고한다.
