# 작성자 질문

작성자가 실제로 질문한 내용을 보존할 때 읽는다. 기준 예시는 [KRaft 글](../../_posts/kafka/2026-11-15-kraft.md)이다.

- 질문은 관련 슬라이드 안에 넣지 않고 바깥의 `aside.author-questions`에 둔다. 슬라이드와 aside를 `div.slide-with-question`으로 감싼다.
- 각 질문은 `details.author-question`으로 접고 펼치게 한다. 기존 CSS를 사용한다. 1200px 이상 화면에서는 슬라이드 왼쪽 여백에 떠서 보이고(카드 줄에는 끼지 않는다), 그보다 좁으면 슬라이드 아래에 나온다.
- summary에 `Q. 질문 내용`을 바로 적는다. 별도 "작성자 질문" 제목을 반복하지 않는다.
- 질문의 뜻과 구체적인 의문을 보존한다. 답은 용어의 뜻, 이유, 구체적인 예 순서로 쉽게 쓴다.
- 처음 읽는 데 꼭 필요한 설명은 본문에도 적는다. 필수 개념을 접힌 답변에만 숨기지 않는다.
- 작성자가 묻지 않은 질문을 자동으로 만들어 실제 작성자 질문처럼 표시하지 않는다.
- `details` 내부에는 빈 줄이나 마크다운 문법을 넣지 않는다.
