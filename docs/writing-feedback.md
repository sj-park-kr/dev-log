## 목적과 독자: 이번 대화의 최종 기준

주니어 개발자와 바이브 코딩을 하는 사람이 기술의 개념을 먼저 잡도록 돕는 블로그다. 일상 비유와 그림으로 역할·관계·흐름을 추상화하고, 이를 실제 기술 용어와 연결한다. 처음부터 세부 구현·설정·운영 지식을 요구하지 않는다. 과거의 "초등학생도 이해"는 쉬운 설명의 기준이며 실제 독자층을 뜻하지 않는다. 과거 심화 요청도 시니어용 상세 자료를 매번 넣으라는 뜻으로 해석하지 않는다.

## 현재 채택한 글 형식

1. 도입: 이 글에서 풀 질문 한 줄 → 문제 상황 → 읽고 알게 될 내용.
2. 문제 제시: 기술 이름보다 그 기술이 없을 때 생기는 불편을 먼저 보여 준다.
3. 개념별 설명: 같은 시리즈의 일관된 비유 → 바로 이어서 같은 개념의 실제 역할과 동작.
4. 관계와 한계: 다른 개념과 어떻게 연결되고, 어떤 문제까지 해결하는지 설명한다. 설정·버전·내부 구조는 개념 이해에 필요한 만큼만 쓴다.
5. 마무리: 대응표와 별도 정리 묶음 없이, 주의사항은 관련 개념 옆의 "이럴 땐 조심해요" 슬라이드에 두고 마지막 슬라이드로 "한눈에 다시 보기"(아이콘 + 용어 + 한 줄) 하나를 둔다.

전체는 `lesson lesson-hierarchy`, 상위 묶음은 `slide-group`과 h2, 하위 슬라이드는 `section.slide`와 h3다. 각 묶음은 하위 슬라이드를 둘 이상 둔다. 각 슬라이드는 그림이나 표 + `point` 한 문장 + `explain` 2~3문장으로 쓴다. 표 정리와 "한눈에 다시 보기"는 explain을 생략할 수 있다. 그림의 사물은 Lucide 아이콘으로 그린다. 말투는 짧은 "~해요"체다.

## 예전 지시와 지금 지시의 차이

- 초기에는 쉬운 설명·개발자용 심화 탭을 요청했으나 이후 명시적으로 통합을 요청했다. 현재는 탭 없는 한 흐름이 기준이다.
- 처음의 "글을 최대한 적게"는 이후 "너무 축약됐다"는 수정으로 구체화됐다. 짧은 설명으로 맥락을 충분히 주는 것이 기준이다.
- 자료조사·작성의 위임과 최종 검토를 나누려는 선호도 있었다. 이는 운영 방식이며, 모든 자동 글쓰기에 여러 에이전트가 필요하다는 뜻은 아니다.
- 이번 요청으로 모바일 화면 검증은 기본 작업에서 제외했다. 빌드·데스크톱 검증을 기본으로 하고 모바일 확인은 별도 요청 때만 한다.
- 이번 목적 재설명에 따라 글의 기본 깊이는 주니어·바이브 코딩 독자의 개념 형성에 맞춘다. 새 글에 상세 설정표·버전 이력·구현 구조를 일률적으로 채우지 않는다. 기존 글을 고칠 때 이미 있는 정확한 사실은 임의로 지우지 않는다.

## 그림·필기에 대해 조사로 확인한 것

작성자가 "ADHD 독자도 읽기 쉽게, 글자보다 그림", "구조화한 필기가 보기 좋았다"고 해서 조사한 내용이다. 확인한 것과 못 한 것을 나눠 적는다.

- **설명하는 그림은 돕고 장식 그림은 해친다.** Mayer의 멀티미디어 학습 원칙(그림과 글을 가까이 두기, 불필요한 것 덜기, 같은 말을 글과 그림에 중복하지 않기)과 Harp & Mayer(1998)의 장식 삽화 연구가 근거다. 그래서 아이콘은 설명 용도만 쓰고 그림 속 글자는 라벨 수준으로 줄인다. ([요약](https://edtechbooks.org/designing_transmedia_learning_environments/principles_of_multimedia_design), [Harp & Mayer](https://link.springer.com/article/10.3758/BF03193412))
- **ADHD 독자를 위한 설계가 입증된 것은 아니다.** 중복 정보가 부하를 키울 수 있다는 가설 수준의 연구만 있어서 위 일반 원칙에 맞추는 정도로 쓴다.
- **어떤 필기 형식이 더 낫다는 강한 근거는 없다.** 코넬 노트·마인드맵 연구는 결과가 갈린다. 공통 조언은 정리한 것을 다시 보는 구조다. 그래서 마지막에 다시 보기 슬라이드를 둔다. ([필기 효과 메타분석 개요](https://www.bohrium.com/paper-details/what-limits-the-encoding-effect-of-note-taking-a-meta-analytic-examination/812306422900457472-6126), [코넬 노트](https://community.pepperdine.edu/seaver/center-teaching-excellence/blog/posts/better-notes.htm))
- 학원 강사나 학생의 실제 후기는 거의 찾지 못했다. 위 내용은 연구와 대학 학습지원센터 자료만 근거다.
