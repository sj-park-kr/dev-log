<details class="origin">
<summary>더 알아보기: 누가 왜 만들었을까?</summary>
<p>Compose의 출발은 영국 런던의 작은 회사 Orchard가 만든 오픈 소스 도구 <b>Fig</b>예요. 벤 퍼스먼(Ben Firshman)과 아난드 프라사드(Aanand Prasad)가 Docker로 개발 환경을 빠르게 띄우려고 만들었어요. Docker, Inc.가 <b>2014년 7월</b> Orchard를 인수했어요.</p>
<p><b>2015년 2월 25일</b> 나온 1.1.0에서 Fig는 Docker Compose로 이름이 바뀌었고 명령도 <code>fig</code>에서 <code>docker-compose</code>로 바뀌었어요. 이 첫 Compose(v1)는 Python으로 만들었고 2020년에 발표한 v2는 Go로 다시 만들어 <code>docker compose</code>처럼 docker 명령 안으로 들어갔어요. v1은 2023년 7월부터 업데이트가 끊겼어요.</p>
<p>compose는 영어로 여러 부분을 모아 하나를 구성한다는 뜻이에요. 여러 컨테이너를 모아 앱 하나를 구성하는 도구라는 이름이에요.</p>
<p>참고: <a href="https://github.com/docker/compose/releases/tag/1.1.0">Compose 1.1.0 릴리스 노트</a> · <a href="https://www.businesswire.com/news/home/20140723005443/en/Docker-Acquires-Orchard-to-Extend-Platform-Leadership">Docker의 Orchard 인수 발표</a> · <a href="https://docs.docker.com/compose/intro/history/">Compose의 역사</a> · <a href="https://docs.docker.com/compose/releases/migrate/">Compose V2로 옮기기</a></p>
</details>

<summary>초보 독자 Q. 비밀번호를 파일에 그대로 적어도 되나요?</summary>
<p>A. 조리대에 건네는 설정값(환경 변수)은 주문서의 environment에 적어요. 이 예에서 웹은 DB_ADDRESS=db:5432를 읽고 DB는 POSTGRES_PASSWORD=example을 받아요. example은 설명용 값이에요. 실제 비밀번호를 공유하는 설정 파일에 적지 말고 외부 비밀 파일 등으로 넘겨요. Compose secrets와 PostgreSQL의 POSTGRES_PASSWORD_FILE을 쓰면 앱이 허용된 비밀 파일을 읽게 할 수 있어요. <a href="https://docs.docker.com/compose/how-tos/use-secrets/">비밀 정보 전달 안내</a>를 참고해요.</p>

<aside class="author-questions" aria-label="초보 독자 질문 목록">
<details class="author-question">
<summary>초보 독자 Q. docker compose up을 치면 화면이 계속 붙잡혀 있나요?</summary>
<p>A. 맞아요. 기본으로는 컨테이너들의 로그가 화면에 계속 나와요. <code>Ctrl+C</code>를 누르면 멈추고 <code>docker compose up -d</code>처럼 <code>-d</code>를 붙이면 화면을 붙잡지 않고 뒤에서 실행해요.</p>
</details>
<details class="author-question">
<summary>초보 독자 Q. 코드를 고치면 web 컨테이너에 바로 반영되나요?</summary>
<p>A. 이미지에 복사해 둔 코드는 자동으로 바뀌지 않아요. <code>docker compose up --build</code>로 이미지를 다시 빌드하면 반영돼요.</p>
<p>빌드 없이 바로 반영하고 싶다면 <a href="{{ '/2026/11/15/docker-volume/' | relative_url }}">2편의 바인드 마운트</a>를 compose.yaml의 web 서비스 volumes에 적어 코드 폴더를 컨테이너에 연결해요.</p>
</details>
<details class="author-question">
<summary>초보 독자 Q. Compose는 따로 설치해야 하나요?</summary>
<p>A. Docker Desktop에는 처음부터 들어 있어요. 리눅스 서버에서는 Docker Engine과 별도로 Compose 플러그인을 설치해야 할 수 있어요. 설치되어 있는지는 <code>docker compose version</code>으로 확인해요.</p>
</details>
<details class="author-question">
<summary>초보 독자 Q. Ctrl+C로 멈추는 것과 down은 뭐가 다른가요?</summary>
<p>A. 화면에 붙여 실행한 <code>docker compose up</code>에서 Ctrl+C를 누르면 실행만 멈추고 컨테이너와 네트워크는 남아요. down은 멈춘 뒤 그것들까지 지우며 기본으로 볼륨은 남겨요.</p>
</details>
